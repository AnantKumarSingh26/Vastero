# Vastero
 
Vastero is an online clothing marketplace where sellers can list and sell their clothing products, and buyers can browse, shop, and purchase fashion items with ease.
 
## Features
 
- 👕 Sellers can add and manage clothing products
- 🛍️ Buyers can browse and purchase products
- 🔍 Search and explore fashion collections
- 📱 Responsive and user-friendly interface
- 🔐 Secure authentication for users
- 🛒 Shopping cart functionality
 
## Tech Stack
 
- Frontend: React
- Backend: Node.js / Express
- Database: MongoDB
- Styling: CSS / SCSS
 
## Getting Started
 
### Clone the Repository
 
```bash
git clone https://github.com/AnantKumarSingh26/Vastero.git
cd Vastero
```
 
### Install Dependencies
 
```bash
npm install
```
 
### Start Development Server
 
```bash
npm start
```
